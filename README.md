# Real-World Git & GitHub Workflow Simulation

This project is a part of my **Module 6 Assignment**, where I simulated a professional software development workflow using Git and GitHub.

## 🚀 Tasks Completed:
* **Local Setup:** Initialized a local Git repository and made the first commit.
* **Branching:** Created a new feature branch to work on a specific part of the website.
* **Merging:** Successfully merged the feature branch back into the main branch.
* **GitHub Connection:** Connected the local repository to GitHub and pushed the code.
* **Conflict Resolution:** Simulated and resolved a manual merge conflict between local and remote changes.
* **Pull Request:** Created and merged a Pull Request (PR) on GitHub.

## 🛠️ Technologies Used:
* HTML5
* Git (Version Control)
* GitHub (Remote Repository)

## 📂 Project Structure:
* `index.html`: Main file containing basic HTML structure and practice content.
* `.git`: Version control history.
